Wordly 初期版

■ 起動方法（Windows）
1. このフォルダを開く
2. フォルダ内のアドレスバーに cmd と入力して Enter
3. 次を実行
   py -m http.server 8000
   ※ py が使えない場合は python -m http.server 8000
4. ブラウザで http://localhost:8000 を開く
5. 終了時はコマンドプロンプトで Ctrl + C

■ 仕様
- 起動時に data/versions.json を読み込み、記載された全バージョンの単語を順番に結合します。
- 各バージョンJSONには、そのリリースで追加された単語だけを記録します。
- 単語帳はクリックで表裏を切り替えるカード式です。前へ/次へで移動します。
- アプリ内の単語追加機能はありません。新しい単語は新しいバージョンJSONに追加してください。
- クイズは四択で、英語→日本語 / 日本語→英語を選べます。

■ バージョン追加例
1. data/versions/v1.0.1.json を作成し、version を v1.0.1 にして追加分の words だけを入れる
2. data/versions.json の latest を v1.0.1 に変更
3. versions 配列の末尾に "v1.0.1" を追加

※ バージョン番号は単語数ではなく、リリースごとに patch を1増やします。
